# 碳循環計算機

一個純前端的碳循環飲食計算工具，無需安裝，開箱即用。

**Live demo：** https://lininu.github.io/carb-cycle-calc/

## 什麼是碳循環？

碳循環（Carb Cycling）根據當天活動量調整碳水化合物攝取量，同時保持蛋白質與脂肪相對穩定。是目前主流的增肌減脂策略之一。

## 計算邏輯

1. **BMR**（女性 Mifflin-St Jeor）：`(10×體重) + (6.25×身高) − (5×年齡) − 161`
2. **TDEE**：`BMR × 活動係數`
3. 設定目標赤字（建議 −200～−500 kcal）
4. **高碳日**（訓練日）：碳水 = 體重 × 3.5g，固定
5. **低碳日**（休息日）：碳水從目標週平均反推，確保總熱量 ≥ BMR
6. **中碳日**（剩餘天數）：碳水 = 高低平均
7. 蛋白質固定：體重 × 2.2g；脂肪固定：體重 × 0.8g

## 可調參數

| 參數 | 說明 |
|------|------|
| 體重 / 身高 / 年齡 | 基本資料 |
| 活動程度 | 影響 TDEE 的活動係數 |
| 訓練天數 | 高碳日天數 |
| 休息天數 | 低碳日天數，中碳日 = 7 − 訓練 − 休息 |
| 減脂赤字 | 目標每日熱量缺口，直接影響低碳日碳水量 |
